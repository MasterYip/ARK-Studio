# Getting help

- Read the [project README](README.md) and the [documentation index](docs/README.md).
- Search the [issues](https://github.com/MasterYip/ARK-Studio/issues) for the
  same question or problem.
- If nothing matches, open an issue with the bug report or feature request
  template. Leave out private data such as server addresses, tokens, user names
  and project content.

Security problems are reported privately; see [SECURITY.md](SECURITY.md).
